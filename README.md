# Perficient Zone Billing

UAE-focused invoicing and business finance platform for customers, quotes, invoices, payments, expenses, projects, time tracking, receivables, VAT records, reports, customer portals and business documents.

## Migration
Source baseline: Hatchable v16. Migration target: Hostinger Node.js Web App with PostgreSQL/Supabase services.

This repository is private and is being used as the migration source of truth.
